# NovaHub 品牌图标规范

## 核心概念

NovaHub 的中文名是“星汇”。标记表达“分散能力汇聚为一次明确行动”：

- 三颗小星：内置能力、第三方插件、用户工作流
- 三条轨迹：搜索、授权与组合形成的统一入口
- 中心四角星：Nova，新星爆发与即时完成
- 中心蓝点：稳定的宿主核心，强调能力汇聚后仍由 NovaHub 控制

标记不是字母 `N` 的装饰变体，也不是抽象数据图表。它必须优先读成“节点汇聚成新星”。

## 资产

| 文件 | 用途 | 背景 |
|---|---|---|
| `novahub-app-icon.svg` | 应用程序、安装器、商店和大尺寸品牌展示 | 自带深色底 |
| `novahub-mark.svg` | 标题栏、设置侧栏、文档和 About 页面 | 深色或品牌中性底 |
| `novahub-symbol-mono.svg` | Windows 托盘、macOS 菜单栏、高对比度模式 | 继承宿主前景色 |
| `novahub-icon-specimen.svg` | 设计评审与尺寸验收板 | 自带画板底色 |

## 几何规则

- 基础网格：`64 × 64`
- 主星视觉中心：`43, 32`
- 能力节点中心：`9,17`、`6,32`、`9,47`
- 安全区：四周至少保留图标边长的 `10%`
- 彩色标记最小尺寸：`24 px`
- `16–20 px` 使用单色版本，避免三个状态色因像素压缩失真
- 不旋转、不镜像、不改变节点数量，不把中心星替换成字母或通用闪电符号

## 颜色

| 角色 | 色值 |
|---|---|
| 宿主中性底 | `#202327` |
| 汇聚轨迹 / 宿主核心 | `#6EA8FF` |
| 内置能力节点 | `#57C995` |
| 插件能力节点 | `#F2B35B` |
| 用户工作流节点 | `#FF7B7B` |
| Nova 主星 | `#F5F7FA` |

颜色不是区分节点的唯一手段：三个节点有独立位置，单色模式仍保持完整语义。

## 平台导出

- Windows：从 `novahub-app-icon.svg` 导出 `16/20/24/32/48/64/128/256 px` PNG 并打包为 ICO
- macOS：导出 `16/32/64/128/256/512/1024 px` PNG，生成 ICNS；系统菜单栏使用单色模板图
- 文档和网站：优先直接使用 SVG，禁止对 SVG 做非等比拉伸
- 所有 PNG 导出使用 sRGB，保留透明通道，不额外添加投影或圆角

## 验收

- 在 24、32、64 px 下中心 Nova 轮廓连续，无粘连或断裂
- 深色、浅色、高对比度背景上均可辨识
- 与 16/20 px 功能图标并列时，品牌图标不会被误认成搜索、发送或播放按钮
- 标题栏使用 `aria-hidden`，旁边由 `NovaHub` 文本提供可访问名称；独立展示时使用 SVG 内置标题与描述
